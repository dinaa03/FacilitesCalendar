# Bridgewater PTC - Site Visibility Calendar

This version has no passkey or sign-in screen.

## Run in VS Code
1. Keep `index.html`, `styles.css`, `app.js`, and `README.md` together.
2. Open the folder in VS Code.
3. Install **Live Server** by Ritwick Dey.
4. Open `index.html` and click **Go Live**.

The calendar opens immediately. Month/Week/Day views, filters, Today summary, and add/edit/delete remain. Entries save in the browser on that device using localStorage.
